# MiniMind 个人贡献与问题排查

本项目的个人工作是复现训练、环境排查、源码阅读和结果分析。汇总记录的四个代码文件改动为中文注释，另新增四篇源码笔记，没有模型结构或训练算法的功能性创新。

## 环境排查

- 为 RTX 5070 Laptop 的 CUDA 兼容问题尝试不同构建，通过 `torch.cuda.get_arch_list()` 和张量运算检查 GPU 支持；汇总记录最终使用 cu128 构建。版本和问题应结合旧安装历史及运行快照复核。
- 排查 WinError 126，检查 torch DLL，并安装 llvm-openmp；保存为当时排查过程，不视为所有 DLL 问题的通用解决方法。
- 整理 Python 与 numpy 的版本冲突，最终记录 Python 3.10.20 和 numpy 1.26.4。
- 采用包含上游 issue 771 修复的代码版本，训练脚本先导入 datasets 再导入 torch。该修复属于上游贡献。
- 三次训练均显式设置 num_workers 0；汇总将规避 Windows 多进程问题标为推断，不能声称已有原始报错证明。

## 训练与分析

在单卡 8 GB 笔记本 GPU 上完成 1 轮预训练和独立的 SFT 1 轮、2 轮对比；预训练采用梯度累积，使用 SwanLab 记录训练指标。源码笔记覆盖 RMSNorm、RoPE、GQA、SwiGLU、损失计算和生成流程。

分析发现训练 loss 与少量问答的知识准确性并不一致，并记录重复、异常符号和技术幻觉。未固定评估 seed 是实验限制，现有样例不能支持过拟合或能力全面提升等结论。

- 排查 Windows CUDA 与 DLL 兼容问题，阅读并注释模型及训练源码，通过梯度累积完成预训练，并使用 SwanLab 跟踪 loss、学习率与显存。
